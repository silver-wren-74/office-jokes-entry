A tiny program for the Make.fun competition **Make the AI Judge Laugh:
Office Jokes**.

## What it does

Running `main.py` writes a single original one-line office joke — about the
reply-all thread that refused to die — to `/output/entry.txt`. The joke is
under 200 characters, as the competition gate requires.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies beyond Python 3.
